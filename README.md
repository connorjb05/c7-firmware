# C7 RC Car Firmware

Firmware for the C7 RC car project, built with PlatformIO for an ESP32-S3 DevKitC-1 board using the Arduino framework.

The firmware receives controller input over Bluetooth Low Energy, drives the ESC, steering servo, and transmission servo, reads vehicle sensors, and uses the onboard status LED to show connection and safety state.

## Project Status

This project is still in active development.

Current focus areas:

- Bluetooth controller input
- ESC throttle and braking control
- Steering servo control
- Two-speed transmission servo control
- RPM and temperature sensor support
- Connection timeout fail-safe behavior

Calibration is still needed for steering angles, gear servo positions, and any final drivetrain tuning.

## Hardware Target

- Board: ESP32-S3 DevKitC-1
- Framework: Arduino
- PlatformIO environment: `esp32-s3-devkitc-1`
- Flash: 16 MB
- PSRAM: 8 MB octal PSRAM
- Serial monitor speed: `115200`
- Upload speed: `921600`

## Firmware Modules

| Module | Purpose |
| --- | --- |
| `BluetoothController` | BLE advertising, connection tracking, and controller packet decoding |
| `ECU` | ESC output, throttle shaping, braking, and drivetrain power control |
| `TCM` | Transmission gear target and shift timing |
| `SCM` | Steering servo output |
| `VehicleSensors` | Motor/output RPM and motor/battery temperature sensors |
| `StatusLED` | Boot, connection, timeout, error, and safe-mode LED states |
| `Modules` | Shared access point for firmware module instances |

## Bluetooth Control

The firmware advertises as:

```text
C7-RC
```

BLE UUIDs:

| Item | UUID |
| --- | --- |
| Service | `c7000001-7c7c-4c7c-8c7c-c7c7c7c7c7c7` |
| Control characteristic | `c7000002-7c7c-4c7c-8c7c-c7c7c7c7c7c7` |

The control characteristic accepts a 10-byte write packet:

| Byte | Meaning |
| ---: | --- |
| 0 | Magic byte, must be `0xC7` |
| 1 | Protocol version, currently `1` |
| 2 | Sequence number |
| 3 | Flags: bit 0 = lights, bit 1 = brake |
| 4 | Gear: `0` neutral, `1` first, `2` second |
| 5 | Drive mode |
| 6-7 | Throttle, signed 16-bit little endian, range `-1000` to `1000` |
| 8-9 | Steering, signed 16-bit little endian, range `-1000` to `1000` |

Throttle and steering are converted to floating-point values from `-1.0` to `1.0`.

## Safety Behavior

If the controller disconnects or control packets stop arriving, the firmware treats the controller as timed out. The default timeout is 300 ms.

On timeout, the firmware calls `stop()` on the drivetrain, steering, Bluetooth, sensors, and status LED modules. This is intended to put the car into a safer state instead of continuing with stale input.

## Status LED

| State | LED behavior |
| --- | --- |
| Booting | Blue |
| Waiting for connection | Amber blink |
| Connected | Green |
| Connection timeout | Red |
| Error | Red |
| Critical error | Fast red blink |
| Safe mode | Purple |

## Dependencies

PlatformIO installs these libraries from `platformio.ini`:

- `madhephaestus/ESP32Servo`
- `bblanchon/ArduinoJson`
- `h2zero/NimBLE-Arduino`

The `.pio` folder is generated by PlatformIO and is intentionally ignored by Git.

## Project Structure

```text
include/        Header files and shared firmware definitions
src/            Main firmware implementation
lib/            Project-specific libraries, if needed later
test/           PlatformIO test folder
platformio.ini  PlatformIO board, build, upload, and dependency config
```

## Development Notes

- Keep generated build files out of Git.
- Update `include/Pins.h` when wiring changes.
- Calibrate steering and transmission servo angles before hard driving.
- Keep the timeout fail-safe working whenever changing Bluetooth or control code.
- Add telemetry back to the controller after the sensor data path is finalized.
